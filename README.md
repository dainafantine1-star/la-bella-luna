# La Bella Luna — Cerimonial

Versão atual do site, refeita com base no layout do Indaiá Eventos, preservando a identidade do La Bella Luna. Fotografias reais, abertura em tela cheia, seleção de celebrações, cenas fotográficas, galeria horizontal e formulário com nome, data, tipo de evento e número de convidados.

## Publicar na Vercel

Importe este repositório em https://vercel.com/new e clique em Deploy. A configuração está pronta em `vercel.json`:

- Framework: Other
- Root Directory: raiz do repositório
- Build Command: `npm run build`
- Output Directory: `dist`

Não há dependências ou variáveis de ambiente necessárias. As imagens e fontes estão no repositório.

## Estrutura

- `dist/index.html`: página e formulário
- `dist/style.css`: layout, responsividade e movimentos
- `dist/script.js`: seleção de evento, cenas, galeria, menu e mensagem do WhatsApp
- `dist/assets`: fotografias, símbolo da marca e fontes

O formulário prepara uma mensagem para o WhatsApp oficial (71) 99140-9542. O visitante revisa e envia; disponibilidade e proposta são confirmadas pela equipe.
